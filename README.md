A curated, community-driven collection of programming, computer science, cybersecurity, and tech-related books, notes, and resources. 

Built to make learning accessible for everyone, everywhere. Contributions are always welcome!

---

## 📂 Directory Structure

To keep everything clean and easily searchable, resources are organized into folders:

* `programming/` - Python, JavaScript, C++, Go, and other languages.
* `cs-fundamentals/` - Data Structures, Algorithms, Computer Architecture, and Systems.
* `devops-security/` - Linux, Cloud Computing, Cybersecurity, and Networking.
* `ai-ml/` - Artificial Intelligence, Machine Learning, and Data Science.

---

## 🚀 How to Contribute

We love community contributions! If you have a useful book, cheat sheet, or study guide to share:

1. **Fork** this repository.
2. **Add** your PDF or resource file inside the appropriate folder (or create a new one if needed).
3. **Commit** your changes with a clear message (e.g., `Add Clean Code PDF`).
4. Submit a **Pull Request (PR)**.

---

## 🛠️ Guidelines for Contributors
* Please ensure that the shared materials are open-source, free to share, or educational notes.
* Keep file names clean, descriptive, and free of special characters (use hyphens instead of spaces).
